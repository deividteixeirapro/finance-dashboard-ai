# 💰 Finance Dashboard Full-Stack

Um aplicativo web moderno de gestão financeira pessoal para controle de receitas, despesas e visualização de dados financeiros.

## 🚀 Tecnologias Utilizadas
- **Back-end:** Node.js, Express, JavaScript
- **Arquitetura:** API RESTful com separação clara de rotas
